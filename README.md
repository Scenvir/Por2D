# Por2D · 四向重力版

Por2D 是一款二维传送门解谜游戏。你控制一个淡黄色矩形角色，在白墙上放置相互连接的蓝门和橙门，利用传送改变位置、速度方向与身体朝向，最终以正确姿态抵达灰色出口，按 E 过关。

本版本加入可自由切换的四向重力。按 G 让重力按「下 → 左 → 上 → 右」循环，墙壁和天花板也能成为支撑面。重力选择与身体朝向独立，为路线和姿态解谜提供更多可能。

本仓库是 [基础重构版](https://github.com/Scenvir/Por2D_Reconstruction) 的四向重力扩展，适合尝试改变落地方向、重新规划传送路线的玩家。基础版侧重固定重力下的位置、惯性与姿态解谜；本版进一步让玩家主动选择重力方向。两版均生成 `Por2D.exe`，请放在各自目录运行。

## 游戏特色

- **位置、姿态与惯性解谜**：两扇门双向连通，身体和速度随门的方向变换；相同深浅的渐变位置彼此对应。
- **身体跨门操作**：角色可以同时露在两端。身体占比较大的一端会锁定并显示细金色边框，另一端在空间允许时仍可重新放置。
- **实时射门预览**：默认开启，按 Q 切换。蓝、橙箭头分别表示可放置的门，两种都能放时并列显示；绿色虚线和轮廓提示位置，两种都不能放时显示红色叉号。
- **中文关卡呈现**：15 个正式关卡配有中文名称和评语，入场时播放约 3 秒的短动画，可按任意键或点击鼠标跳过。
- **便捷重试与选关**：R 重开本关，Esc 暂停并进入选关菜单。触碰地图任意边界会重开本关；死亡和 R 重试不重复播放入场动画。
- **原生 Windows 窗口**：支持窗口和等比例全屏显示，无需 EasyX。

## 开始游玩

已有构建产物时，双击本目录的 `build/Por2D.exe`。启动后先看到自动演示画面，按任意键进入选关菜单，从 **Level 0「概念」** 开始即可。

| 操作 | 功能 |
| --- | --- |
| WASD | 沿支撑面移动或逆重力跳跃，具体对应关系见下表 |
| G | 切换重力，下 → 左 → 上 → 右 |
| 鼠标左键 / 右键 | 按下并松开，放置蓝门 / 橙门 |
| Q | 开关射门预览 |
| E | 与出口的位置、朝向匹配时过关 |
| R | 重开本关；全部通关后重新开始 |
| Esc | 选关菜单 / 继续游戏 |
| F11 / Alt+Enter | 全屏 / 窗口 |
| F1 / F2 | 头部红点 / 辅助网格 |

切换重力保留当前身体朝向和速度，穿门不会改变所选重力；重开或换关恢复向下。

| 重力方向 | 沿支撑面移动 | 跳跃 | 无额外作用的顺重力键 |
| --- | --- | --- | --- |
| 下 | A / D：左 / 右 | W | S |
| 左 | W / S：上 / 下 | D | A |
| 上 | A / D：左 / 右 | S | W |
| 右 | W / S：上 / 下 | A | D |

跳跃需要身体接触当前重力方向的支撑面。按键以屏幕方向为参照，身体穿门后的朝向不会改变这张表。可以先在 Level 0 练习移动与 E 过关，再按 G 观察角色向新方向下落。

放门时瞄准连续三格白墙的中间格，松开左键放蓝门、松开右键放橙门。两扇门都存在时才能传送。预览中的蓝、橙箭头表示可放置的颜色；门外的金色细框表示该门因身体跨门而暂时锁定。出口同时要求位置和身体朝向匹配；遇到困难可按 R 重试。

选关菜单可用鼠标点击，或用方向键选择、Enter 开始，PageUp / PageDown 翻页。选择关卡会重开该关，“继续游戏”保留暂停状态。

## 关卡

正式关卡按显示编号排列：

| Level | 名称 | Level | 名称 |
| --- | --- | --- | --- |
| 0 | 概念 | 8 | 铁砧 |
| 1 | 高山 | 9 | 倒立 |
| 2 | 旋转 | 10 | 远见 |
| 3 | 远跳 | 11 | 生死逆转 |
| 4 | 大脑 | 12 | 阀门 |
| 5 | 穿梭 | 13 | 深渊 |
| 6 | 支点 | 14 | 生死逆转（最终关） |
| 7 | 裂缝 | — | — |

原 Level 13、14 依次前移为 Level 12、13，原 Level 12（源码 ID 16）移至 Level 14；完成最终关即通关。源码 ID 保持不变，回放脚本中的 `level ID` 无需修改。本版源码 ID 16 保留本版原有「生死逆转」地图。

菜单末尾另有两张无出口的实验地图，适合自由练习。显示编号与源地图 ID 不同：正式战役对应的地图 ID 依次为 `0, 5, 6, 7, 8, 9, 10, 3, 14, 11, 12, 15, 13, 4, 16`。

## 可视化地图编辑器

双击打开 [editor/index.html](editor/index.html)，即可在浏览器中离线制作地图，无需安装依赖或启动服务器。

- 网格为 50×30，每格 20 像素；上方和左侧显示坐标，鼠标移动时显示格坐标及像素坐标。
- 数字键 1–5 或工具按钮选择空气、可开门方块、不可开门方块、出生点、过关点。左键拖动绘制，右键擦除。
- 出生点与过关点分别只有一个，可设置四种头部朝向；实际身体占用范围会显示在网格上。
- 支持视图缩放、撤销/重做、地图名称与评语。保存 JSON 后可通过“打开地图”继续编辑。
- 按 V 或点击“框选 / 移动”，拖出矩形选择方块及与矩形相交的出生点、出口，再拖动蓝色选中元素整体移动（按网格对齐）。空白格不会覆盖目标内容；超出边界或覆盖未选方块时不能放置。在其他位置拖动重新框选，Esc 取消拖动或清除选择，一次整体移动可整体撤销 / 重做。
- 选择“实心矩形”后，从一个角拖到对角，预览范围并松开填充；右键批量擦除方块，Esc 取消。一次矩形操作可整体撤销。出生点与出口仍为单点放置。
- 出口以方向箭头、头端横线及“头朝上/右/下/左”文字显示过关姿态要求，该方向与重力方向独立。
- “检查地图”提示标记缺失、身体与墙重叠、越界等问题；草稿仍可保存，但有这些问题时不能导出 C++。

JSON 是编辑器保存格式，游戏目前不能直接加载。导出的 C++ 包含 `por2::makeCustomLevel()`，使用现有 `Level` / `TileMap` 类型；要在游戏中游玩，需要将函数加入源码、在 `makeLevel` 中接入并配置关卡选择，再重新编译。编辑器不会自动修改内置关卡。

浏览器下载的 JSON 文件是地图存档，请在关闭或刷新前保存。编辑器测试可在本目录执行 `node editor/model.test.js`（需要 Node.js 和 `g++`，后者用于检查导出代码）。
浏览器交互回归执行 `node editor/browser.test.js`（默认使用 Windows 上的 Edge，也可追加 Chrome / Edge 可执行文件路径），覆盖框选、整体移动、撤销 / 重做、取消、边界、缩放与画笔操作。

## 导入脚本与可视化回放

在选关菜单选中关卡（或进入关卡），按 **F6** 选择操作脚本。导入后从该关卡起点播放；如果文件开头有 `level ID`，则使用文件指定的源码地图 ID。回放时显示当前指令、帧进度、播放速度，以及蓝色或橙色的射门目标十字标记；普通移动和射门输入在回放期间被屏蔽。

| 按键 | 功能 |
| --- | --- |
| 空格 | 暂停 / 继续 |
| `.`（句号） | 暂停并前进一帧 |
| R | 从脚本起点重播 |
| F8 | 切换 1× / 0.25× 速度 |
| F7 | 退出回放，接手当前状态 |
| F6 | 导入另一份脚本 |
| Esc | 打开选关菜单，暂停推进回放 |

失去窗口焦点会暂停回放，返回后按空格继续。脚本结束或成功过关后画面停止推进，并显示结果；R 可重播。非法脚本会显示错误行号，不替换当前游戏。最多接受 1,000,000 帧。

脚本为 UTF-8 文本（可带 BOM），每行一条指令，支持空行和 `#` 注释。每帧对应 20 毫秒：

```text
# level 使用源码 ID，不是菜单编号；省略时使用当前关卡
level 0
d 8
aw 3
s 0 260 389
z 8
e 1
```

`a/d/w` 表示按住对应键，`aw/dw` 表示同时按键，后面的整数是持续帧数；`z N` 等待，`e N` 尝试出口，`r N` 重开。`s 0 X Y` 向逻辑屏幕坐标 (X,Y) 发射蓝门，`s 1 X Y` 发射橙门，每条占一帧。坐标基于 1000×600 游戏画面，不受窗口缩放影响。上述示例仅说明格式，不保证过关。

也可从命令行直接播放，或用无窗口模式验证：

```powershell
.\build\Por2D.exe --level 16 --replay .\path\solution.txt
.\build\Por2D.exe --headless --level 16 --replay .\path\solution.txt
```

无窗口回放默认执行完整脚本；`--frames N` 可限制帧数。输出 `replay=cleared` 表示已过关，`ended` 表示脚本执行完但未过关，`partial` 表示达到帧数限制。两个版本的关卡和物理不同，操作文件不保证跨版本通用。

## 从源码构建

项目使用 C++17，Windows 构建需要带 Windows 工具链的 `g++`（例如 LLVM-MinGW）和 PowerShell。以下命令均在本 README 所在目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\build\Por2D.exe
```

脚本会生成 `build/Por2D.exe`。可通过 `-Compiler` 指定编译器，或通过 `-DebugBuild` 启用调试构建。

也可使用 CMake：

```powershell
cmake -S . -B build-cmake -DBUILD_TESTING=OFF
cmake --build build-cmake --config Release
```

窗口程序面向 Windows。需要运行回归测试时，从 [原始源码仓库](https://github.com/Scenvir/Por2D-origin) 取得 `NewlyUpdateMap.cpp`，放到本项目目录的上一级，再执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test`。测试需要该文件，单独构建游戏不需要。

常用启动参数：

```powershell
.\build\Por2D.exe --fullscreen
# --level 使用源地图 ID：5 对应菜单里的 Level 1「高山」
.\build\Por2D.exe --level 5
.\build\Por2D.exe --headless --level 5 --frames 60 --screenshot .\build\level1.bmp
.\build\Por2D.exe --window-smoke-test
```

无窗口模式用于模拟和地图截图，不展示窗口绘制的入场文字动画。

## 项目结构与背景

项目在原始地图与传送变换基础上重构，使用浮点碰撞、分步运动，以及同一帧内的角色、投影和瞄准更新。工作区的 `por2_reconstructed/` 是基础版，`Por2D/` 是四向重力版；共同功能在两版中保持同步。

- `src/levels.cpp`：地图、中文名称与评语。
- `src/portal.cpp`、`src/physics.cpp`：射线、传送变换与碰撞运动。
- `src/game.cpp`：关卡流程和游戏状态。
- `src/render.cpp`、`src/main.cpp`：画面、射门预览、窗口交互和入场动画。
- `tests/`：核心逻辑回归测试。

本仓库的使用入口为本 README。基础版的玩法介绍与教程见 [Por2D_Reconstruction](https://github.com/Scenvir/Por2D_Reconstruction)，其中固定向下重力的操作规则与本版有所不同。
